# Hero 首屏个人优势改造

- 日期：2026-11-18
- 状态：已批准，已实施
- 分支：feat/3d-visual-redesign

## 意图与原因

站点核心是简历，但当前首屏更像项目展示页：简介是通用描述，技能 chips 与下方「专业技能」整节重复，免责说明占据黄金位置。招聘方在首屏 5 秒内应先记住「全链路 AI 落地」这一标签，并能看到可验证的证据。

## 目标

- 保留主标题、eyebrow、两个 Demo CTA 与右侧 3D 场景。
- 将通用简介替换为一句定位：从 Agent 引擎、RAG 检索到前端交互，全链路落地。
- 将技能 chips 替换为 3 条带证据的个人优势，招聘方扫一眼即可建立「能独立交付」的印象。
- 免责说明缩为一行小字，不再占据视觉重心。

## 非目标

- 不修改标题、eyebrow、CTA 文案与顺序。
- 不修改 3D 场景、项目区、专业技能板块、导航与页脚。
- 不新增依赖，不引入新的版式系统。

## 反目标

- 首屏变成大段自述或形容词堆砌。
- 与下方「专业技能」内容重复。
- 为了信息量牺牲可读性，或让左侧文案压过右侧 3D 主体。

## 方案

- **A 证据式优势列表（采用）**：一句定位 + 三条编号优势，每条附一个可验证事实。信息密度与可扫读性最好，符合简历阅读习惯，也与编辑排版风格一致。
- **B 三张能力小卡（弃用）**：视觉更像能力看板，但左栏会变拥挤，与右侧 3D 场景争抢注意力，中文小卡信息密度低。
- **C 最小改动 + 数据条（弃用）**：保留简介与 chips，只在 CTA 下加数据条。风险最低，但个人优势仍不显性，首屏依旧偏项目展示。

## 设计细节

- `src/data/profile.ts`
  - 新增 `positioning` 与 `strengths: { index, title, detail }[]`。
  - 移除已无引用的 `skills` 字段。
- `src/components/Hero.tsx`
  - 标题保持「让 Agent 的每一步都可以被看见。」
  - 简介替换为 `PROFILE.positioning`。
  - 删除 `TechChips`，改为语义化优势列表（`ul` / `li`，编号 `aria-hidden`）。
  - CTA 保持不变；免责说明缩为一行。
- `src/styles/global.css`
  - 新增 `.hero__positioning`、`.hero__strengths`、`.strength`、`.strength__index`、`.strength__title`、`.strength__detail`。
  - 沿用现有颜色、字体、圆角与间距 token。
  - ≤720px 时三条优势纵向排列并下调字号。
- 文案：
  - 定位：从 Agent 引擎、RAG 检索到前端交互，全链路落地。
  - 01 全链路交付 — Agent 引擎 / RAG / 前端，一人打通
  - 02 把 AI 做成产品 — 流式渲染 · 首屏 15s→2s · 50–60fps
  - 03 复杂业务与协作 — Workflow 主 · LLM 辅；5–7 人团队
  - 免责：Demo 为纯前端实现：检索与调度真实运行，LLM 判断由规则模拟。

## 约束

- 所有数字与事实必须来自现有 `profile.ts` / README，不新增未经证实的指标。
- 保持现有视觉语言与响应式断点体系。

## 留给实现

- 序号列宽、行距与 CTA 的垂直间距按现有 8px 节奏微调。
- 默认不加可视标题「核心优势」，由编号与定位句表达；若需要更显性可加 mono 小标。
